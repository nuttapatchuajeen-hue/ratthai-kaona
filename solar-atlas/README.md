# แผนที่ระบบสุริยะ (Solar Atlas)

แบบจำลองระบบสุริยะ 3 มิติ ที่ทำงานได้เหมือน NASA Eyes on the Solar System
แต่**เขียนขึ้นใหม่ทั้งหมดและไม่ใช้ทรัพย์สินของใครเลย** — ไม่มีไฟล์ภาพ ไม่มีโค้ดที่คัดลอกมา
ไม่มีโลโก้หรือชื่อของหน่วยงานอวกาศใด

---

## 1. ศึกษาของจริงมาก่อน: NASA Eyes ทำงานยังไง

จากการเปิด `eyes.nasa.gov/apps/solar-system` แล้วดูว่ามันโหลดอะไรบ้าง สรุปสถาปัตยกรรมได้ดังนี้

| ชิ้นส่วน | ของ NASA Eyes | ของเรา |
|---|---|---|
| เอนจิน | เว็บแอป WebGL แบ่งเป็นบันเดิล `vendors.js` / `app.js` / `preload.js` | `three.js` (MIT) + โค้ดของเราเอง |
| ตำแหน่งวัตถุ | ไฟล์ ephemeris ไบนารีชื่อ `.dyn` สตรีมทีละช่วงเวลา เช่น `dynamo/moon/earth/orb/243.dyn` แยกเป็น `orb` (วงโคจร) `pos` (ตำแหน่ง) `ori`/`quat` (การหันตัว) | คำนวณสดจากองค์ประกอบวงโคจรเคปเลอร์ ไม่มีไฟล์ข้อมูล ไม่มีเน็ตเวิร์ก |
| พื้นผิวดาว | ภาพถ่ายจริงตัดเป็นคิวบ์แมป 6 หน้า หลายระดับความละเอียด (`maps/mercury/color_4_0.png` → `color_512_5.png`) สตรีมตามระยะกล้อง | สร้างด้วย Perlin noise 3 มิติ ตอนเปิดหน้าเว็บ (~4 วินาที) |
| ดาวฤกษ์ | แคตาล็อกไบนารี `stars.0..5.bin` + สไปรต์ `milky_way.png` | ปั่นเองจากการสุ่มแบบมีการกระจายจริง + กาแล็กซีเกลียวลอการิทึม |
| ช่วงสเกล | ผิวดาว → ทั้งกาแล็กซี ด้วย scene graph หลายชั้น | ฉากแยก 3 ชั้น + เลื่อนจุดกำเนิดตามกล้อง (ดูข้อ 3) |
| UI | แถบบน · แผงซ้าย 3 แท็บ (Info / Toolbox / View Options) · คอนโซลเวลาล่าง · แถบไอคอนขวา | โครงเดียวกัน แต่ออกแบบหน้าตาใหม่และเป็นภาษาไทย |

**สิ่งที่ยากที่สุดของแอปแบบนี้ไม่ใช่กราฟิก แต่คือ "ช่วงตัวเลข"** — รัศมีโลก 6,371 กม.
กับระยะถึงขอบกาแล็กซี 4×10¹⁷ กม. ต่างกัน 14 หลัก ซึ่งเกินความละเอียดของ float 32 บิตที่ GPU ใช้
วิธีแก้อยู่ในข้อ 3

## 2. ไฟล์ในโฟลเดอร์นี้

```
index.html        โครงหน้าและ UI ทั้งหมด (โหลด 3 ไฟล์ล่าง)
style.css         ธีมเดียว: คอนโซลสังเกตการณ์กลางคืน
data.js           องค์ประกอบวงโคจร ข้อมูลกายภาพ ข้อความไทย/อังกฤษ
textures.js       Perlin noise + สูตรระบายสีผิวของดาวแต่ละดวง
app.js            เอนจิน: ดาราศาสตร์ ฉาก 3 มิติ กล้อง และการผูก UI
standalone.html   ไฟล์เดียวจบ (รวมทุกอย่างไว้ข้างใน) สำหรับก๊อปไปวางที่อื่น
```

### เอาไปใช้ยังไง

- **ทั้งโฟลเดอร์** — ก๊อป `solar-atlas/` ไปวางในเว็บ แล้วลิงก์ไป `/solar-atlas/`
- **ไฟล์เดียว** — ใช้ `standalone.html` ไฟล์เดียว วางที่ไหนก็ได้ (ขนาด ~165 KB)
- **ฝังในหน้าอื่น** — `<iframe src="/solar-atlas/" style="width:100%;aspect-ratio:16/9;border:0"></iframe>`

ต้องต่ออินเทอร์เน็ตเพื่อโหลด `three.js` จาก cdnjs และฟอนต์ IBM Plex จาก Google Fonts
ถ้าอยากให้ทำงานออฟไลน์ ให้ดาวน์โหลดสองอย่างนี้มาไว้ในเครื่องแล้วแก้ `<script src>` กับ `<link>`

> แก้ไขที่ `index.html` / `style.css` / `data.js` / `textures.js` / `app.js` เป็นหลัก
> ส่วน `standalone.html` เป็นไฟล์ที่ **สร้างขึ้นจากไฟล์เหล่านั้น** — ถ้าแก้แล้วต้องสร้างใหม่
> ด้วยการเอาเนื้อ `style.css` ไปแทน `<link rel="stylesheet">` และเอาเนื้อ `.js` แต่ละไฟล์
> ไปแทน `<script src>` ตามลำดับเดิม

## 3. เทคนิคสำคัญในโค้ด

**ตำแหน่งดาวเคราะห์** ใช้องค์ประกอบวงโคจรโดยประมาณยุค J2000 (a, e, I, L, ϖ, Ω พร้อมอัตราเปลี่ยนต่อศตวรรษ)
แก้สมการเคปเลอร์ `E − e·sin E = M` ด้วยวิธีนิวตัน 8 รอบ แล้วแปลงเข้าพิกัดสุริยวิถี
คลาดเคลื่อนระดับลิปดาในช่วงปี ค.ศ. 1800–2050 — ดูฟังก์ชัน `planetPos()` ใน `app.js`

**ดวงจันทร์ของโลก** ใช้สูตรความละเอียดต่ำมาตรฐาน (พจน์คาบหลัก 6 พจน์) ที่ `lunarPos()`
ส่วนดวงจันทร์ดวงอื่นเป็นวงรีเคปเลอร์ในระนาบศูนย์สูตรของดาวแม่

**ความแม่นของตัวเลขตอนซูมเข้า** — ทุกตำแหน่งเก็บเป็นกิโลเมตรใน JS (double 64 บิต)
แล้วก่อนส่งเข้า three.js จะ **ลบด้วยตำแหน่งของวัตถุที่กำลังโฟกัส** เสมอ
พูดง่าย ๆ คือย้ายจุดกำเนิดของฉากไปอยู่ที่ดาวที่คุณกำลังดู ตัวเลขที่เข้า GPU จึงเล็กเสมอ
ผิวดาวเลยไม่สั่นตอนซูมใกล้ (ดู `toScene()` และ `updateOrigin()`) เสริมด้วย `logarithmicDepthBuffer`

**สามฉากซ้อนกัน** วาดเรียงจากไกลไปใกล้ในแต่ละเฟรม
1. `galScene` — ทางช้างเผือก ย่อมาตราส่วนเหลือ 1 หน่วย = 1,000 ปีแสง กล้องยืนที่ตำแหน่งดวงอาทิตย์จริง (ห่างใจกลาง 26,000 ปีแสง)
2. `skyScene` — ท้องฟ้าที่มองจากย่านดวงอาทิตย์ เป็นทรงกลมรอบกล้อง
3. `scene` — ระบบสุริยะจริง

สองชั้นแรกไล่สลับกันด้วย `smoothstep` บนลอการิทึมของระยะกล้อง ช่วง 5 → 3,200 ปีแสง
ซูมออกไปเรื่อย ๆ ดาวรอบตัวจะจางแล้วกาแล็กซีจะโผล่มาแทน

**จานกาแล็กซี** ไม่ได้โปรยจุดให้ถี่ แต่คำนวณความสว่างจากสูตรตรง ๆ ในแฟรกเมนต์เชเดอร์
(จานเอ็กซ์โพเนนเชียล + ดุมกลาง + แขนกังหันเกลียวลอการิทึม 4 แขน) แล้วโปรยจุดดาวทับเพื่อให้มีเม็ด
แขนของทั้งสองชั้นใช้สมการเกลียวเดียวกันจึงวางตัวตรงกันพอดี

**พื้นผิวดาว** ประเมิน Perlin noise 3 มิติ บน "เวกเตอร์ทิศทาง" ของแต่ละพิกเซล ไม่ใช่บนพิกัด u,v
ทำให้ไม่มีรอยต่อและไม่ยืดที่ขั้ว จากนั้นแต่ละดวงมีสูตรระบายสีของตัวเองใน `PAINTERS`
(หลุมอุกกาบาตของดาวพุธ แถบลมของดาวพฤหัสบดี ทวีปกับเมฆของโลก รอยแตกของยูโรปา ฯลฯ)

## 4. เรื่องลิขสิทธิ์ — ทำไมชุดนี้เอาไปใช้ได้

| ประเด็น | สถานะ |
|---|---|
| ภาพพื้นผิวดาว | ไม่มีไฟล์ภาพเลย สร้างด้วยโค้ดตอนรัน |
| ภาพกาแล็กซี | สร้างด้วยสูตร ไม่ใช่ภาพถ่ายหรือภาพวาดของใคร |
| โค้ด | เขียนใหม่ทั้งหมด ไม่ได้อ่านหรือคัดลอกจากบันเดิลของ NASA |
| ไลบรารี | `three.js` — MIT License |
| ฟอนต์ | IBM Plex Sans Thai / IBM Plex Mono — SIL Open Font License |
| ตัวเลขวงโคจรและข้อมูลกายภาพ | ข้อเท็จจริงทางวิทยาศาสตร์ ไม่เข้าข่ายงานอันมีลิขสิทธิ์ |
| คำบรรยาย | เรียบเรียงขึ้นใหม่ ไม่ได้แปลหรือคัดจากที่ใด |
| เครื่องหมายการค้า | ไม่มีโลโก้ ชื่อ หรือตราสัญลักษณ์ของหน่วยงานใด |

**ข้อควรรู้เพิ่ม** ภาพถ่ายของ NASA เองส่วนใหญ่ใช้ได้ฟรี (ไม่มีลิขสิทธิ์แบบงานรัฐบาลสหรัฐ)
แต่มีข้อยกเว้นที่พลาดกันบ่อย — ภาพบางส่วนเป็นของพันธมิตร เช่น ESA หรือมหาวิทยาลัย
และ**ตราสัญลักษณ์ NASA เป็นเครื่องหมายที่คุ้มครองแยกต่างหาก ห้ามใช้โดยไม่ขออนุญาต**
ชุดนี้เลี่ยงทั้งหมดด้วยการไม่แตะอะไรของใครเลย

ถ้าภายหลังอยากได้ผิวดาวสวยแบบภาพถ่ายจริง สามารถสลับไปใช้แผนที่พื้นผิวสาธารณสมบัติได้
โดยแก้เฉพาะจุดที่สร้าง texture ใน `makeBody()` — โครงสร้างที่เหลือไม่ต้องแตะ

## 5. ข้อจำกัดที่ควรรู้

- องค์ประกอบวงโคจรแม่นในช่วงปี ค.ศ. 1800–2050 นอกช่วงนี้จะเริ่มเพี้ยน
- ตำแหน่งดวงจันทร์ (ยกเว้นของโลก) เป็นวงรีอย่างง่าย ไม่ได้คิดการรบกวนจากดาวดวงอื่น
- ขนาดดาวแสดงตามจริงเสมอ เว้นแต่เปิดโหมด "ขยายให้เห็น" ในแท็บมุมมอง
- ทางช้างเผือกเป็นแบบจำลองเชิงศิลป์ที่อิงโครงสร้างจริง (4 แขน ดวงอาทิตย์ห่างใจกลาง 26,000 ปีแสง) ไม่ใช่แผนที่ดาวรายดวง
- ไม่เหมาะกับงานที่ต้องการความแม่นระดับนำทางยานอวกาศ

## 7. เว็บนี้มีแบบจำลองระบบสุริยะสองตัว

| | `solar-atlas/` (โฟลเดอร์นี้) | `stats/orrery.html` |
|---|---|---|
| จุดเด่น | ตำแหน่งตามวันเวลาจริง · ซูมถึงกาแล็กซี · ผิวดาวสร้างด้วยโค้ด · สองภาษา | ดาวหางฮัลเลย์ · เชื่อมกับระบบเสียง BGM/SFX ของเว็บแม่ · การ์ดข้อมูลไทย |
| พึ่งพาไฟล์อื่นในเว็บ | ไม่พึ่งเลย | ผูกกับ `js/cyber-sfx.js` และ `js/cyber-audio.js` |
| ลิขสิทธิ์ทรัพย์สิน | ไม่มีไฟล์ภาพภายนอกเลย | มีการดึงพื้นผิวจากภายนอก |

**ยังไม่ได้รวมสองตัวนี้เข้าด้วยกัน** — ตั้งใจวางไว้คนละโฟลเดอร์ก่อน
ถ้าจะเลือกใช้ตัวเดียว แนะนำให้ย้ายของที่ขาดข้ามมา (ดาวหางฮัลเลย์ กับ hook เสียง)
แล้วค่อยเปลี่ยน `stats/orrery.html` เป็นหน้า redirect เหมือนที่ทำกับอีกสามไฟล์
