# 3D Solar System Orrery & Comet Halley (Thai Planetarium Edition)

โปรเจกต์แบบจำลองระบบสุริยะ 3 มิติ สมจริงระดับ NASA พร้อมดาวหางฮัลเลย์ การ์ดข้อมูลภาษาไทย และแถบควบคุมเวลา

## ⚠️ ไฟล์จริงย้ายไปที่ `stats/orrery.html` แล้ว

เดิมหน้านี้ถูกก๊อปไว้ 4 ที่ในเว็บ เนื้อหาเหมือนกันทุกไบต์ (`stats/orrery.html`,
`stats/solar-orrery.html`, `solar-system-orrery/index.html`, `solar-system-orrery/orrery.html`)
แก้ทีต้องไล่แก้ 4 ไฟล์ ตอนนี้ยุบเหลือไฟล์จริงไฟล์เดียวคือ **`stats/orrery.html`**
ส่วนอีก 3 ไฟล์เปลี่ยนเป็นหน้า redirect เพื่อไม่ให้ลิงก์เก่าพัง

**จะแก้ตัวแบบจำลอง ให้แก้ที่ `stats/orrery.html` เท่านั้น**

## ถ้าอยากแยกไปเป็นเว็บเดี่ยว

ก๊อป `stats/orrery.html` ไปวางเป็น `index.html` ในโฟลเดอร์ของโปรเจกต์ใหม่ แล้วลบบรรทัด
`<script src="../js/cyber-sfx.js">` กับ `<script src="../js/cyber-audio.js">` ท้ายไฟล์ออก
(สองบรรทัดนั้นผูกกับเว็บแม่) ที่เหลือไม่ต้องแก้ — ตัวหน้าดึง Three.js จาก CDN
ไม่ต้องพึ่งไฟล์อื่นในเว็บเลย

## คุณสมบัติเด่น
- ☀️ ดวงอาทิตย์เปล่งแสงเรืองรองนวลตา พร้อมออร่าโคโรนาและแฉกแสง
- 🌍 ดาวเคราะห์ 8 ดวง + โลก Blue Marble + เมฆหมุนวน + แสงสะท้อนผิวน้ำทะเล
- 🌕 ดวงจันทร์ของโลก, ดวงจันทร์กาลิเลียน 4 ดวงของดาวพฤหัสบดี, ดวงจันทร์ไททันของดาวเสาร์
- ☄️ ดาวหางฮัลเลย์ 3D แท้ พร้อมหางไอออนสีน้ำเงินครามและหางฝุ่นสีขาวนวล
- 📊 การ์ดข้อมูลดาราศาสตร์ภาษาไทย คลิกดาวดวงใดก็ได้เพื่อเปิดดู
- ⏱️ แถบปรับสปีดเวลา (Time Warp): หยุด, 1x, 5x, 20x, 100x
